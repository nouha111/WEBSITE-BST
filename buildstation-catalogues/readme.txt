Manage Build Station brand catalogues with segment filters, PDF viewing, downloads, and one-click duplication.

== Installation ==
1. In WordPress, open Plugins > Add New > Upload Plugin.
2. Choose buildstation-catalogues.zip, click Install Now, then Activate.
3. Open Catalogues > Add New Catalogue.
4. Add the title, brand name, logo, catalogue PDF, featured cover image, and Segment.
5. Publish the catalogue.
6. Add shortcode [buildstation_catalogues] to a page. Use [buildstation_catalogues segment="sanitary-ware"] on a segment page.

== Duplicating a catalogue ==
Open Catalogues > All Catalogues and click Duplicate below any item. Replace the title, logo, PDF, cover, and segment, then publish.
